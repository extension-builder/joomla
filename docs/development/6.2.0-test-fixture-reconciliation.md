## Deleted helper ownership

The stable commit deletes `Utilities/GetHelperExtrusion.php`. Its `between()`
and `allBetween()` implementations already exist in `Utilities/GetHelper.php`.
No production callers of the deleted name remain. The obsolete test class and
its ownership entry are removed; `GetHelperTest` retains the complete/empty/
missing delimiter cases, distinct-value ordering, duplicates, incomplete
segments, multi-character delimiters, and existing 501-value safety bound.
No production declaration is added to the debt baseline.

## Runtime fixtures and boundaries

The stable `AllowView` renderer emits native `Factory`/`Text` aliases and the
component language key for the administrator denial message. Its isolated
method evaluator now supplies those native imports as a complete generated
model header does. Joomla's application and language state are restored by the
existing `JoomlaTestCase` lifecycle. Actual access decisions, administrator
edit checks, and JSON:API error handlers continue to execute unchanged.

Loading the JCB language fixture verifies JCB's translated messages. It does
not prove that an arbitrary generated extension owns the stable renderer's
`COM_COMPONENTBUILDER_NOT_AUTHORISED` key; that pre-existing localization
concern remains separate from these fixture corrections.
