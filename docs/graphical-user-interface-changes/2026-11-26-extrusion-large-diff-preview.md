# Explain oversized diffs when the detail is opened

## Change identity

- First changed on 2026-11-26 by Codex.
- Branch `fix/extrusion-large-diff-preview`. Ready for review.

## Explicit permission

The request asks for an oversized-diff message when the user clicks a diff in the Extrusion administrator view. The protected change is confined to the detail response in `admin/src/Model/AjaxModel.php`. The existing disclosure renders that response.

## Purpose and rationale

The review needs counts. A user opening a row also requests its detailed lines, which can exceed the line or memory budget for a preview. The model translates the resolver's omitted-preview result into guidance visible inside the opened row.

## Affected paths

| Change | Protected path |
| --- | --- |
| Modified | `admin/src/Model/AjaxModel.php` |
| Created, moved, renamed or deleted | None |

## Implementation details

`AjaxModel::extrusionRecords()` requests hunks only for the selected row. If a comparison exceeds the preview budget, it releases any partially built records and returns `null`. `AjaxModel::extrusionDiff()` sends a translatable message through the existing row-level error field. `fetchDiff()` and `renderDiff()` in the existing Extrusion script already escape and display that text inside the disclosure.

## Impact

The review and change totals remain available. Opening an oversized row displays an explanation, a direct comparison alternative and guidance for memory-limited servers. Ordinary rows retain their side-by-side detail. The message appears as text in the existing keyboard-operable disclosure. This change affects the installed administrator application across compiler targets.
